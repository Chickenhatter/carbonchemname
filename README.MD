<h1>Carbon Chemistry Naming</h1>
Name Alkanes, Alkenes and Alkanols up to 10 carbon long. 
Press the shift button to be able to acess a menu for settings, default is naming Alkane molecules.

In this menu:
-The number at top left is for the maximum amount of branches can appear on a molecule. 
-The button in dead center means you name the molecuels like 'nonene' or 'butanol'
-Bottom left is for summoning a new molecule
-Right top is for allowing Alkanol molecules
-Right bottom is for allowing Alkene molecules

While not in shift menu there is a button in the bottom right corner which allows the name to be revealed
In the top left corner is a counter that counts how many times you got a molecule correct besides from if you pressed to see the name of the molecule

Good luck in trying to guess the names
