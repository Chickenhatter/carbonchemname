<h1>Carbon Chemistry Naming</h1>
<p>Name Alkanes, Alkenes and Alkanols up to 10 carbon long. </p>
<p>Press the shift button to be able to acess a menu for settings, default is naming Alkane molecules.</p>

<p>In this menu:</p>
<p>-The number at top left is for the maximum amount of branches can appear on a molecule. </p>
<p>-The button in dead center means you name the molecuels like 'nonene' or 'butanol'</p>
<p>-Bottom left is for summoning a new molecule</p>
<p>-Right top is for allowing Alkanol molecules</p>
<p>-Right bottom is for allowing Alkene molecules</p>

<p>While not in shift menu there is a button in the bottom right corner which allows the name to be revealed</p>
<p>In the top left corner is a counter that counts how many times you got a molecule correct besides from if you pressed to see the name of the molecule</p>

<p>Good luck in trying to guess the names</p>
